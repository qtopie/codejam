# Algorithms — 经典算法知识库

按 [经典算法知识纲要](https://qtopie.github.io/notes/codejam/classic-algorithms/) 组织，覆盖数据结构、算法范式、图论、字符串、数论与 DP 优化。

## 目录结构

| 主题 | 说明 |
|------|------|
| [`core-concepts/`](core-concepts/) | 核心概念：复杂度分析、递推与主定理、正确性证明 |
| [`data-structures/`](data-structures/) | 数据结构：数组/链表、栈/队列、哈希、树/堆、并查集 |
| [`paradigms/`](paradigms/) | 算法范式：分治、DP、贪心、回溯、双指针/滑动窗口、前缀差分、二分 |
| [`graph/`](graph/) | 图论：遍历、环检测、割点桥、最短路、MST、拓扑、流与匹配 |
| [`string/`](string/) | 字符串：KMP、Trie、后缀结构、Manacher |
| [`math/`](math/) | 数论与计算几何 |
| [`dp-optimization/`](dp-optimization/) | DP 优化（进阶）：单调队列、斜率优化、Knuth |

# 核心概念

- **复杂度分析**: 时间/空间、摊还；渐进符号 O/Θ/Ω；常见 O(1)/O(log n)/O(n log n)。
- **递推与主定理**: 分治类递归复杂度估计（`T(n) = a·T(n/b) + f(n)` 三情形）。
- **正确性证明**: 不变式、数学归纳、反证；贪心的交换论证/割性质。
- **随机化与概率**: 随机快速选择、哈希冲突期望分析、生日悖论。

## 公式速查

- 主定理: `T(n) = a·T(n/b) + f(n)`，比较 `f(n)` 与 `n^(log_b a)`。
- 摊还分析（动态数组倍增）: 均摊插入 = O(1)。
- 哈希负载因子: α = n/m，拉链法查找 ≈ O(1 + α)。

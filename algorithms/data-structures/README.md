# 数据结构

- **线性结构**: 数组 vs 链表（连续内存随机访问 vs 插删灵活）。
- **栈与队列**: LIFO / FIFO；双端队列。
- **哈希结构**: 集合/映射、开放定址/拉链法、布隆过滤器。
- **树与堆**: BST、AVL/红黑树、Trie、线段树、树状数组、二叉堆。
- **并查集**: 合并-查找，按秩合并 + 路径压缩。
